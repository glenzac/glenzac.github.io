title: Probably the best image compression online tool
---


I don't want my free WordPress media quota running out before  I can afford a premium plan. So I rely heavily on compressing the images I upload.

I've tried several online tools and found [https://tinyjpg.com/](https://tinyjpg.com/)  to be the best.

![Screenshot\_2018-11-09 TinyJPG – Compress JPEG images intelligently(2).png](@assets/wp-content/uploads/2018/11/screenshot_2018-11-09-tinyjpg-e28093-compress-jpeg-images-intelligently2.png)

Above all there is almost no noticeable change in quality.

![Screenshot_2018-11-09 TinyJPG – Compress JPEG images intelligently(1)(1).png](@assets/wp-content/uploads/2018/11/screenshot_2018-11-09-tinyjpg-e28093-compress-jpeg-images-intelligently11.png)

The first photo was huge and 1.2MB it was compressed to just 403KB.

### Update: 11/02/20

I don't use an online tool anymore. I've found an offline open source tool that is way better than tinyjpg and also offers more control over the compression. Tinyjpg just compresses without any visible loss in quality.

The open source tool is called [RIOT - Radical Image Optimization Tool](https://riot-optimizer.com/)

RIOT makes it easy to configure the level of compression, helps resize images and also downsample or reduce the no. of colours of an image. All this helps to really tightly squeeze images down. I'll probably write a detailed review on it when I get time.

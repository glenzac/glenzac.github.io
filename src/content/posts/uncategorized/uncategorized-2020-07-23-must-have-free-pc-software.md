title: Must-have free PC software
---
- To create and open archives: [7-zip](https://www.7-zip.org/)
- Blue light filter: [F.lux](https://justgetflux.com/)
- For taking screenshots and annotation: [ShareX](https://getsharex.com/)
- Music Player: [Music Bee](https://getmusicbee.com/)
- Floating lyric on Windows: [MiniLyrics](https://www.crintsoft.com/)
- e-book reader - [Calibre](https://calibre-ebook.com/)
- Password Manager: [KeepassXC](https://keepassxc.org/)
- Windows Scripting tool for automation: [Autohotkey](https://www.autohotkey.com/)
- Post it notes for your PC: [Stickies](https://www.zhornsoftware.co.uk/stickies/)
- Local file synchronization: [Syncthing](https://syncthing.net/)
- For all note taking tasks and drawing: [One Note](https://www.onenote.com)
- File hash verification: [HashTab](http://implbits.com/products/hashtab/)
- Organizing research work: [Zotero](https://www.zotero.org/)
- Flashcards : [Anki](https://apps.ankiweb.net/)
